# ClipFin Windows 1.0.59 Beta 5

Beta 4 테스트에서 남아 있던 메시지 첫 입력 표시와 한글 첫 줄 커서 문제를 재수정한 테스트 버전입니다. 정식은 1.0.58을 유지합니다.

## Beta 4 이후 변경

- ‘메시지를 입력하세요.’ 안내 문구를 편집기와 독립된 형제 창으로 배치했습니다. 편집기 내부 스크롤에 문구가 따라 내려가지 않도록 했고 첫 문자·한글 조합 처리 전에 숨깁니다.
- 메시지의 일반 텍스트 입력창을 Windows 기본 Unicode Edit로 전환했습니다. RichEdit의 첫 줄 글꼴/조합 레이아웃 처리 경로를 사용하지 않으며 입력·선택·실행취소는 Windows 컨트롤이 처리합니다.
- 조합 중 전송·배경 갱신 방지, 표·이미지 붙여넣기, 여러 줄 입력과 스크롤 동작을 유지합니다. 메모 편집기의 RichEdit와 자동저장은 이번 수정 범위에 포함하지 않습니다.
- 기존 설정·단축키·대화·메모·첨부자료를 유지합니다. 업데이트는 EXE만 교체합니다.

## 검증 및 확인 요청

Release x64 빌드와 메시지 입력·메모·표 붙여넣기·메신저 배치·자동 다운로드 집중 검사 5개를 통과했습니다. 실제 Windows ScrollWindowEx 호출 후 안내 문구의 화면 좌표가 유지되는지와 편집기보다 위에 표시되는 창 순서를 검사했습니다. 완성형 한글·영문 입력의 커서/선택 보존과 IME 시작·종료 알림 중 동작도 검사했습니다.

실제 키보드 한글 조합 비교 창은 컴퓨터 사용 도구의 앱 실행 승인 대기 시간이 초과돼 열지 못했습니다. 따라서 실제 Microsoft/한컴 입력기의 첫 줄 커서 문제가 해결됐다고 확정하지 않습니다.

1. 빈 메시지 입력창에서 첫 글자를 입력할 때 안내 문구가 내려가지 않고 바로 사라지는지 확인해 주세요.
2. 첫 줄에서 한글을 연속 입력하거나 잠시 멈췄다 이어 입력할 때 커서가 앞뒤로 이동하는지 확인해 주세요.
3. Enter 전송, Shift+Enter 줄바꿈, 표·이미지 붙여넣기가 정상인지 확인해 주세요.
4. 문제가 남으면 입력기 종류(Microsoft/한컴 등)와 버전 번호를 함께 알려주세요.

## 업데이트

앱의 **설정 / 단축키 / 테마 → 업데이트 채널 → 베타 먼저 받기(정식 포함)**를 선택한 뒤 **업데이트 확인**을 실행하세요.

정식 배포는 사용자 테스트와 명시적 승인 후 진행합니다. Android 정식·베타 채널은 이번 Windows 배포에서 변경하지 않습니다.

최종 배포 검사: 집중 UI/메뉴 검사 9종과 업데이트 설치·복구·자료 보존 15개 검사는 통과했습니다. 전체 회귀 검사는 UDP 검색 수신 준비 단계의 시간 초과로 미통과했습니다. 직전 배포본에서도 재현된 기존 환경 문제이며 해당 통신 소스는 변경하지 않았습니다. 전체 통과로 간주하지 않으며 정식 승격 전 추가 확인이 필요합니다.
