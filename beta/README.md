# ClipFin Windows 1.0.60 Beta 3

**도구 / 관리 → 이미지 매크로**를 열면 감시 범위, 패턴 등록, 테스트 및 감시가 순서대로 표시됩니다. 창은 ClipFin의 테마를 따릅니다.

1. **감시 범위**에서 대상 창을 고르고 검색 영역을 지정합니다. 화면 좌표를 감시하려면 **화면에 검색 영역 고정**을 선택합니다.
2. **화면에서 패턴 등록**으로 찾을 이미지를 캡처합니다. 저장해 둔 이미지 파일은 **등록 패턴** 미리보기 위에 한 개씩 놓아 등록합니다. PNG, JPEG, BMP, GIF를 지원하며 가로·세로가 각각 2~256px이어야 합니다.
3. **검색 테스트**에서 감지 위치와 매칭률을 확인하고 **감시 시작**을 누릅니다. **설정 저장**으로 다음 실행에도 같은 패턴과 검색 범위를 사용합니다.

자동 클릭이 실행되면 매칭률이 담긴 토스트가 한 번 표시됩니다. **감시 중지** 또는 **Ctrl+Alt+F11**로 감시를 중지합니다.

앱에서 **설정 / 단축키 / 테마 → 업데이트 채널 → 베타 먼저 받기(정식 포함)**를 선택한 뒤 **업데이트 확인**을 실행하세요.
