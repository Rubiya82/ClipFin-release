# ClipFin Windows 1.0.59 Beta 7

Beta 6에서 검정 조합 표시가 개선됐지만 커서 왕복이 첫 줄에 남는다는 사용자 보고에 따라, 빈 첫 문단의 언어 초기화를 조정한 테스트 버전입니다. 정식은 1.0.58을 유지합니다.

## Beta 6 이후 변경

- 기본 문자 형식의 언어를 영문으로 고정하던 초기화를 제거하고 현재 입력기의 언어로 기본 문단을 초기화합니다.
- 빈 편집기와 입력 문자에 대한 자동 언어 보정을 꺼 첫 문단의 언어가 입력 도중 다시 적용되는 경로를 줄였습니다.
- Beta 6과 같은 인라인 TSF 입력 경로, 글꼴 고정 및 포커스 시 안내 문구 숨김을 유지합니다. 조합 중 문자열·선택 영역을 앱이 강제로 고치거나 확정하지 않습니다.
- 기존 설정·단축키·대화·메모·첨부자료를 유지합니다. 업데이트는 EXE만 교체합니다.

## 검증과 남은 확인

Release x64 빌드와 메시지 입력·메모·표 붙여넣기·메신저 배치·자동 다운로드 집중 검사 5종을 통과했습니다. 추가한 자동 검사는 한글 기본 문단을 설정한 뒤 포커스 이동, 첫째/둘째 줄의 한글·자음 확정 문자, IME 시작/종료 알림 전후의 언어·글꼴 크기·삽입 위치 유지와 지연 배치 후 커서 보존을 확인합니다.

사용자 요청에 따라 자동 검사만 진행했습니다. **빈 문단의 언어 보정이 실제 커서 왕복의 원인이라는 판단은 가설이며, 실제 Microsoft 한글 입력기의 첫 줄 문제가 해결됐다고 확정하지 않습니다.**

1. 첫 줄에서 한글을 연속 입력하거나 잠시 멈췄다 이어 입력할 때 커서가 앞뒤로 움직이는지 확인해 주세요.
2. 둘째 줄과 비교해 첫 줄에만 남는 차이가 있는지 확인해 주세요.
3. 커서만 잠깐 움직이는지, 글자가 실제 앞쪽에 삽입되거나 순서가 바뀌는지도 알려주세요.
4. 검정 조합 표시 개선, 클릭 시 안내 문구 숨김, Enter/Shift+Enter와 표·이미지 붙여넣기가 유지되는지 확인해 주세요.

## 업데이트

앱에서 **설정 / 단축키 / 테마 → 업데이트 채널 → 베타 먼저 받기(정식 포함)**를 선택한 뒤 **업데이트 확인**을 실행하세요.

[Beta 7 ZIP 다운로드](https://github.com/Rubiya82/ClipFin-release/releases/download/v1.0.59-beta.7/ClipFin-1.0.59-beta.7-win-x64.zip) · [릴리스/검증 해시](https://github.com/Rubiya82/ClipFin-release/releases/tag/v1.0.59-beta.7)

정식 배포는 사용자 테스트와 명시적 승인 후 진행합니다. 이번 Windows 베타 게시에서는 Android 정식·베타 채널을 변경하지 않습니다.

최종 배포 검사: 집중 UI/메뉴 검사 9종과 업데이트 설치·복구·자료 보존 15개 검사는 통과했습니다. 전체 회귀 검사는 재실행에서 파일 전송 시험을 통과한 뒤 기존 UDP 검색 수신 준비 단계의 시간 초과로 미통과했습니다. 이전 공개 베타에서도 재현된 제한이며 관련 통신 소스는 변경하지 않았습니다. 전체 통과로 간주하지 않고 정식 승격 전 추가 확인이 필요합니다.
