# ClipFin Windows 1.0.60 Beta 2

**도구 / 관리 → 이미지 매크로 → 이미지 파일로 등록…**에서 기존에 저장해 둔 이미지를 패턴으로 등록할 수 있습니다. PNG, JPEG, BMP, GIF를 지원합니다. 가로·세로가 각각 2~256px이고 밝은 부분과 어두운 부분이 모두 포함된 이미지를 선택하세요. 투명한 부분은 흰 배경으로 처리합니다.

등록 패턴 미리보기를 확인하고 **설정 저장**을 누르면 다음 실행에서도 같은 패턴을 사용합니다. **화면에서 패턴 등록**으로 화면을 직접 캡처하는 방법도 사용할 수 있습니다.

대상 창을 활성화하지 않고 감시하려면 **화면에 검색 영역 고정**을 켜고 **검색 영역 지정**으로 화면에서 위치를 고르세요. 이 모드에서는 지정한 위치에 화면에 보이는 내용을 검사합니다. 앱 위를 다른 창이 가리면 가려진 내용은 감시할 수 없습니다. 고정 옵션을 끄면 검색 영역이 다시 대상 창을 따라갑니다. 모드를 바꾸면 검색 영역을 다시 지정합니다.

이진화 미리보기에서는 찾은 사각형 옆에 매칭률이 표시됩니다. 매칭 기준을 통과하면 사각형 중앙을 클릭하고 포인터를 직전 위치로 복원합니다. **감시 중지** 버튼 또는 **Ctrl+Alt+F11**로 감시를 멈출 수 있습니다. 단축키가 이미 사용 중이어도 감시는 시작됩니다.

감시 중 화면이 같으면 이전 매칭 결과를 재사용합니다. 검색에 시간이 오래 걸리면 다음 캡처 간격을 늘려 CPU 부하를 줄입니다.

앱에서 **설정 / 단축키 / 테마 → 업데이트 채널 → 베타 먼저 받기(정식 포함)**를 선택한 뒤 **업데이트 확인**을 실행하세요.
