# ClipFin Windows 1.0.60 Beta 1

**도구 / 관리 → 이미지 매크로**에서 재생 버튼의 이미지를 찾아 자동으로 클릭할 수 있습니다.

1. **대상 창 선택**으로 자동 클릭할 창을 고릅니다.
2. **패턴 등록**으로 재생 삼각형과 흰 배경을 포함한 사각형을 캡처합니다. **검색 영역 지정**으로 같은 창에서 확인할 범위를 드래그합니다. 검색 범위는 대상 창과 함께 이동합니다.
3. 매칭률과 재클릭 대기시간을 입력하고 **설정 저장**을 누릅니다. 처음 열었을 때 기준은 95%, 대기시간은 2,000ms입니다. 앱을 다시 시작하면 저장된 패턴과 영역을 불러오며 대상 창은 다시 선택합니다.
4. **검색 테스트**로 이진화 화면, 최고 매칭률, 탐지 위치를 확인합니다. **감시 시작**을 누른 뒤 대상 창을 활성화하면 기준을 통과한 사각형의 중심을 클릭합니다. **감시 중지** 또는 **Ctrl+Alt+F12**로 멈출 수 있습니다.

클릭 직전에 포인터를 중심 좌표에 고정하고 클릭 직후 해제합니다. 버튼이 사라졌다가 다시 나타나고 설정한 대기시간도 지났을 때 다음 클릭을 실행합니다.

앱에서 **설정 / 단축키 / 테마 → 업데이트 채널 → 베타 먼저 받기(정식 포함)**를 선택한 뒤 **업데이트 확인**을 실행하세요.

패턴 매칭과 중심 좌표, 재클릭 제어, 메뉴 활성화·창 열기, 파일 전송·메시지 및 업데이트 설치·복구를 자동 검증했습니다. 실제 재생 앱의 화면과 마우스 입력은 베타에서 확인이 필요합니다.
