# ClipFin Windows 1.0.59 Beta 4

메시지·메모 첫 줄 입력과 바탕화면 타일, 메모 목록을 개선한 테스트 버전입니다. 정식은 1.0.58을 유지합니다.

## Beta 3 이후 변경

- 메시지와 메모에서 첫 줄 한글 입력 시 글자/커서 높이가 달라지는 현상을 줄이도록 Windows 편집기의 아시아 문자 크기와 줄 높이 보정을 조정했습니다.
- 축소 메모 타일을 실제 바탕화면 표시 영역에 배치하도록 수정했습니다. 타일을 표시할 수 없으면 펼친 메모를 숨기지 않습니다. 작은 타일의 드래그·더블클릭 복원을 유지합니다.
- 메모 목록을 작업 표시줄/Alt+Tab에서 접근 가능한 독립 창으로 개선했습니다. 큰 두 줄 항목, 메모·휴지통·수신 요청 분류, 제목·본문·발신자·첨부파일 검색과 키보드 조작을 제공합니다.
- 메인 ‘＋ 메모 ▾’의 오른쪽 화살표로 목록을 열 수 있습니다. 메인 화면/메모 편집기에서 Ctrl+F로 목록과 검색에 접근합니다.
- 기존 설정·단축키·대화·메모·첨부파일을 유지합니다. 업데이트는 실행 파일만 교체합니다.

## 확인 요청 및 검증 한계

1. 메시지와 메모 첫 줄에서 실제 한글 입력 시 커서 이동·깜빡임이 개선됐는지 확인해 주세요.
2. 메모 축소 후 현재 위치에 타일이 남는지, Win+D 후 표시 및 이동·더블클릭 복원이 되는지 확인해 주세요.
3. 목록 검색과 메인 버튼 화살표 접근을 확인해 주세요.

빌드와 메모·입력·메뉴·빠른 접근 집중 자동 검사는 통과했습니다. 완성형 한글 입력의 커서/글꼴 검사와 실제 바탕화면 호스트 확인을 수행했습니다. 실제 Microsoft 한글 IME 미확정 조합과 Win+D 후 표시까지 해결됐다고 확정하지 않으며 사용자 재확인이 필요합니다.

전체 회귀 검사는 UDP 검색 리스너 준비 시간 초과로 미통과한 기록이 있습니다. 직전 공개 Beta 3에서도 동일하게 재현됐고, 여러 로컬 UDP 포트의 Windows 접근 제한(10013)이 확인됐습니다. 전체 통과로 간주하지 않습니다. 정식 승격 전 추가 검증이 필요합니다.

## 업데이트
