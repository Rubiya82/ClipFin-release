# ClipFin Windows 1.0.59 Beta 1

메모 UI 개선을 검증하는 테스트 배포입니다. 최신 정식은 1.0.58이며, 사용자 테스트와 명시적 승인 후 정식 배포합니다.

- 정음메모패드 느낌의 메모지 UI: 얇은 상단 도구 모음, 넓은 본문, 하단 자동저장 상태.
- 작은 사각 아이콘을 가로로 배열하고 마우스 오버로 기능 이름을 표시합니다. 새 메모·첨부·공유·항상 위·색상·더보기·타일 축소를 제공하고 글꼴·읽기 전용·목록/검색·숨기기·휴지통은 더보기에서 실행합니다.
- 첨부파일이 있을 때만 첨부 영역을 표시합니다. 창 이동·크기 조절과 기존 메모 자동저장을 유지합니다.
- 메인 화면에 ‘＋ 메모’ 버튼을 추가했습니다.
- 새 메모 기본 단축키는 **Ctrl+Win+Z**입니다. **설정 / 단축키 / 테마 → 단축키 설정…**에서 변경하거나 미지정할 수 있습니다. 기존 여덟 단축키 설정은 유지합니다. 기존 조합이 Ctrl+Win+Z를 사용 중이면 그 조합을 유지하고 새 메모는 미지정합니다.
- 같은 설치와 자료 경로를 사용합니다. 업데이트는 EXE만 교체하며 설정·대화·메모·첨부자료를 유지합니다.

## 받는 방법

1.0.58의 **설정 / 단축키 / 테마 → 업데이트 채널 → 베타 먼저 받기(정식 포함)**를 선택하고 **업데이트 확인**을 실행하세요. ZIP을 직접 받는 경우 기존 앱을 트레이에서도 종료한 뒤 기존 실행 파일을 교체하세요. 자료 폴더를 삭제할 필요가 없습니다.

## 테스트 요청

메모 작성·자동저장·재시작 복원, 상단 아이콘과 더보기, 첨부·공유, 메인 화면의 새 메모 버튼, Ctrl+Win+Z, 단축키 변경과 기존 조합 유지 여부를 확인해 주세요. 실제 Explorer에서 Win+D, 여러 모니터/DPI 및 한글 조합 입력은 사용자 환경에서도 확인이 필요합니다.

베타를 테스트한 뒤 버전 번호와 함께 정식 배포 승인 여부를 알려주세요. 승인 전 정식 채널은 1.0.58을 유지하며 Android는 변경하지 않습니다.
