# ClipFin Windows 1.0.58 Beta 1

정식 배포 전 사용자 테스트용입니다. 최신 정식은 1.0.57을 유지하며, 이번 베타의 확인·승인 후 정식 배포합니다. Android는 1.0.36을 유지합니다.

- 바탕화면 메모: 작은 타일/더블클릭 펼침, 자동 저장·재시작 복원, 색상·글꼴, 읽기 전용·항상 위, 목록·검색, 휴지통·복원, 백업·복원.
- 메모에 파일을 첨부하고 Windows 등록 상대 여러 명에게 발송 시점의 독립 복사본으로 공유합니다. 다른 화면에서는 대응 모니터 작업 영역 비율로 위치를 맞추고 화면 안으로 보정합니다.
- 메모 자동 수신 기본 OFF, 수신 요청 알림 기본 ON. 상대별 허용, 수신/거절 토스트와 이번 요청만 받기를 지원합니다. 닫기·만료 시 저장하지 않습니다. 허용한 상대의 첨부도 자동 저장하며 기본 첨부 한도는 100MiB입니다.
- 캡처 파일 저장은 기존 **Ctrl+Alt+W**와 추가 **Ctrl+Win+X**를 모두 지원합니다.
- **설정 / 단축키 / 테마 → 단축키 설정…**에서 전역 단축키 조합 전체를 변경합니다. 변경값을 기억하고 중복·점유 시 기존 조합으로 복구합니다. 기능 사용 여부는 기존 메뉴에서 설정합니다.
- **업데이트 채널**에서 정식만 또는 베타 포함을 선택합니다. 베타를 먼저 받고 같은 번호의 승인된 정식으로 업데이트해도 설정·대화·메모·첨부자료는 유지합니다.

## 설치와 테스트

최초 베타는 `ClipFin-1.0.58-beta.1-win-x64.zip`을 직접 받아 압축을 풀고, 기존 ClipFin을 트레이에서도 완전히 종료한 다음 `ClipFin.exe`를 실행하세요. 자료 폴더를 지우거나 앱을 제거할 필요가 없습니다. 기존 설치 경로와 자료를 이어 사용합니다.

처음 베타 설치 시 채널 선택 이력이 없으면 베타 포함으로 설정됩니다. 이후 **베타 먼저 받기(정식 포함)** 상태에서 다음 베타와 승인된 정식을 받을 수 있습니다. 정식만 선택해도 현재보다 오래된 정식으로 자동 되돌리지는 않습니다.

확인 요청: 메모 작성·축소·이동·재시작 복원, 파일 첨부, 상대별 수신 요청/자동 수신, Win+D 이후 표시, Ctrl+Alt+W와 Ctrl+Win+X, 단축키 변경/재시작, 업데이트 채널 선택.

## 호환성과 검증 한계

메모 자동 배치는 새 Windows 클라이언트에서 지원합니다. 이전 Windows/Android에는 `.clipfin-memo` 첨부로 표시되며 자동 배치하지 않습니다. 메모 백업 파일에는 본문과 첨부가 평문으로 들어 있습니다.

자동 검사는 격리 Windows 창, 두 TLS 서비스, 화면 좌표/DPI 모델, Explorer 호스트 창 소멸/재생성 및 업데이트 교체로 수행했습니다. 실제 Explorer의 Win+D, 물리적 두 PC 및 복수 모니터, 실제 Office/ChatGPT 붙여넣기와 파일 선택기 지연은 사용자 테스트가 필요합니다. 이 베타는 아직 정식 승인 상태가 아닙니다.
