# ClipFin Windows 1.0.59 Beta 6

Beta 5 테스트에서 보고된 한글 조합의 검정 반전 표시와 안내 문구/캐럿 겹침을 개선하기 위한 테스트 버전입니다. 최신 정식은 1.0.58이며 실제 Microsoft 한글 입력기의 표시 개선은 사용자 재확인이 필요합니다.

## Beta 5 이후 변경

- 빈 입력창을 클릭하거나 Tab 등으로 포커스를 옮기는 즉시 ‘메시지를 입력하세요.’ 문구를 숨깁니다. 포커스가 있는 동안 빈 입력창에서도 안내 문구가 다시 나타나 캐럿을 가리지 않습니다. 빈 상태로 다른 곳에 포커스를 옮기면 안내를 다시 표시합니다.
- 메시지 입력 경로를 인라인 TSF RichEdit로 변경하고 영문/한글 자동 글꼴 전환·이중 글꼴·문자군별 크기 보정을 해제했습니다. 첫 입력 전에 두 문자군의 글꼴과 크기를 UI 글꼴로 맞춥니다.
- 조합 중 앱이 내용·선택 영역·서식을 재작성하거나 조합을 강제로 확정하지 않습니다. 일반 선택 색을 바꾸는 방식으로 검정 조합 표시를 숨기지 않습니다.
- 기존 설정·단축키·대화·메모·첨부자료를 유지합니다. 업데이트는 EXE만 교체합니다.

## 검증과 남은 확인

Release x64 빌드와 메시지 입력·메모·표 붙여넣기·메신저 배치·자동 다운로드 집중 검사 5종을 통과했습니다. 첫 입력 전 기본 글꼴/크기 초기화, 완성형 한글·자음 입력 순서와 커서 유지, 조합 시작/종료 알림 중 앱의 서식·선택 재적용 방지, 실제 마우스 메시지·키보드 포커스에 따른 안내 문구 숨김/복원을 검사했습니다.

사용자는 Microsoft 한글 입력기이며 메모장에서는 밑줄 표시라고 확인했습니다. 요청에 따라 자동 검사만 진행했으며, 실제 Microsoft 입력기의 미확정 조합 표시를 직접 검사한 것으로 간주하지 않습니다. **검정 반전 표시와 첫 줄 커서 현상이 해결됐다고 아직 확정하지 않습니다.**

1. 안내 문구가 보일 때 클릭하면 문구가 즉시 사라지고 빈 입력창의 캐럿이 보이는지 확인해 주세요.
2. 첫 줄에서 한글과 자음만 입력할 때 검정 반전 표시가 개선됐는지 확인해 주세요.
3. 잠깐 멈췄다 이어 입력할 때 커서 왕복이 남아 있는지 확인해 주세요.
4. Enter 전송, Shift+Enter 줄바꿈, 선택·실행취소와 표/이미지 붙여넣기를 확인해 주세요.

## 업데이트

앱에서 **설정 / 단축키 / 테마 → 업데이트 채널 → 베타 먼저 받기(정식 포함)**를 선택한 뒤 **업데이트 확인**을 실행하세요.

[Beta 6 ZIP 다운로드](https://github.com/Rubiya82/ClipFin-release/releases/download/v1.0.59-beta.6/ClipFin-1.0.59-beta.6-win-x64.zip) · [릴리스/검증 해시](https://github.com/Rubiya82/ClipFin-release/releases/tag/v1.0.59-beta.6)

정식 배포는 사용자 테스트와 명시적 승인 후 진행합니다. 이번 Windows 베타 게시에서는 Android 정식·베타 채널을 변경하지 않습니다.

최종 배포 검사: 집중 UI/메뉴 검사 9종과 업데이트 설치·복구·자료 보존 15개 검사는 통과했습니다. 전체 회귀 검사는 UDP 검색 수신 준비 단계의 시간 초과로 미통과했습니다. 이전 공개 베타에서도 재현된 기존 제한이며 관련 통신 소스는 변경하지 않았습니다. 전체 통과로 간주하지 않고 정식 승격 전 추가 확인이 필요합니다.
