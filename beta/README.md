# ClipFin Windows 1.0.63 Beta 1

**도구 / 관리 → 이미지 매크로**에서 **검색 영역 지정**을 눌러 화면에서 감시할 위치를 고르세요. 이미지 매크로는 고정 화면 영역만 사용하며, 해당 영역에 화면에 보이는 내용을 감시합니다.

기존에 저장한 고정 영역과 패턴은 그대로 불러옵니다. 이전에 창 기준으로 설정했다면 패턴, 매칭률 및 재클릭 대기시간을 복원합니다. 검색 영역은 화면에서 다시 지정한 뒤 **설정 저장**을 누르세요.

앱에서 **설정 / 단축키 / 테마 → 업데이트 채널 → 베타 먼저 받기(정식 포함)**를 선택한 뒤 **업데이트 확인**을 실행하세요.
