# ClipFin Windows 1.0.59 Beta 3

메모 자동저장·축소 아이콘과 메시지 입력 표시를 개선한 테스트 배포입니다. 최신 정식은 1.0.58이며 사용자 테스트와 명시적 승인 후 정식 배포합니다.

## Beta 2 이후 변경

- 메모 자동저장: 1초마다 상태를 확인하고, 마지막 입력 후 5초 이상 입력이 없을 때만 저장합니다. 입력이 이어지면 저장을 미루고 한글 조합 중에도 기다립니다.
- 자동저장은 자료와 하단 상태만 갱신합니다. 저장 후 편집창 전체를 다시 배치하거나 본문·서식·커서·선택 영역을 다시 적용하던 경로를 제거했습니다. 명시적인 새 메모·축소·공유 전 저장은 유지합니다.
- 메모 최소화: 현재 위치에 작은 정사각형 메모 아이콘을 남깁니다. 아이콘은 드래그로 이동·배치할 수 있으며, 더블클릭하면 이동한 위치에서 원래 메모 크기로 펼쳐집니다. 제목과 조작 안내는 마우스 오버로 표시합니다.
- 바탕화면에 아이콘을 만들 수 없는 경우에는 편집창을 숨기지 않습니다. 아이콘은 기존 정책대로 바탕화면에 다른 앱 뒤로 배치됩니다.
- 메시지 안내 문구: 입력창에 직접 덧그리지 않고 별도 자식 라벨로 표시합니다. 첫 입력이나 한글 조합이 시작되면 문자 확정 전에도 숨겨 안내 문구가 본문에 겹치거나 두 번째 줄로 이동하지 않도록 개선했습니다.
- 메시지 입력 알림 처리 도중 창 크기를 바꾸지 않고, 100ms 타이머에서 합쳐 적용하도록 변경했습니다. 첫 줄 깜빡임을 줄이기 위한 개선입니다.
- 기존 설정·단축키·대화·메모·첨부자료를 유지합니다. 업데이트는 EXE만 교체합니다.

## 받는 방법

앱의 **설정 / 단축키 / 테마 → 업데이트 채널 → 베타 먼저 받기(정식 포함)**를 선택하고 **업데이트 확인**을 실행하세요. Beta 1·2 사용자는 같은 채널에서 Beta 3로 업데이트할 수 있습니다. ZIP을 직접 받으면 기존 앱을 트레이에서도 종료한 뒤 실행 파일을 교체하세요. 자료 폴더를 삭제할 필요가 없습니다.

## 테스트 요청

1. 메모에 한글·여러 줄을 입력하고 5초 이상 멈춘 뒤 이어 입력할 때 커서가 유지되는지 확인해 주세요.
2. 최소화한 아이콘이 현재 위치에 남고 드래그·더블클릭으로 이동/복원되는지, Win+D 뒤에도 표시되는지 확인해 주세요.
3. 메시지 첫 줄 입력 시 안내 문구가 사라지고 잔상·깜빡임이 개선되는지 확인해 주세요.

네이티브 자동 검사에서 유휴 저장, 커서·선택·실행취소 보존, 아이콘 이동/복원과 메뉴·입력 동작을 확인하고 화면 렌더링을 검토했습니다. 실제 Microsoft 한글 IME의 키 조합·체감 지연 및 실제 Explorer의 Win+D는 사용자 환경에서 재확인이 필요합니다.

테스트 후 버전 번호와 함께 정식 배포 승인 여부를 알려주세요. 승인 전 정식 채널은 1.0.58을 유지하며 Android는 변경하지 않습니다.
