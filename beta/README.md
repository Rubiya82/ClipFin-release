# ClipFin Windows 1.0.61 Beta 1

**도구 / 관리 → 이미지 매크로**에서 **감시 시작**을 누르면 Windows에 화면을 켜 두도록 요청합니다. 감시 중에는 이 요청을 30초마다 갱신하고, 감시 중지 또는 창 닫기 시 이전 전원 요청 상태를 복원합니다.

이미지 매크로 창이 활성 상태일 때는 해당 창으로 전달되는 화면 보호기 시작 요청도 처리합니다. 다른 앱이 활성 상태이거나 Windows의 암호 보호 정책이 적용되면 화면 보호기가 실행될 수 있습니다.

앱에서 **설정 / 단축키 / 테마 → 업데이트 채널 → 베타 먼저 받기(정식 포함)**를 선택한 뒤 **업데이트 확인**을 실행하세요.
