# ClipFin Windows 1.0.59 Beta 8

첫 줄 한글 입력 시 커서가 순간적으로 앞으로 이동하는 현상을 추가 점검한 테스트 버전입니다.

## Beta 7 이후 변경

- 메시지 입력 변경 알림 안에서 즉시 실행하던 안내·전송 버튼·입력창 높이 갱신을 100ms 타이머로 모으고, 네이티브 입력 처리 및 조합 중에는 기다립니다.
- 메모의 첫 수정 시 ‘저장 대기 중’ 표시도 지연 처리합니다. 자동저장은 마지막 입력 후 5초 유휴 조건을 유지하며 입력 처리에 재진입한 저장·화면 갱신을 막습니다.
- IME 종료 후 인위적으로 입력 변경 알림을 다시 보내던 경로를 제거했습니다. 기존 검정 조합 표시 개선과 글꼴 설정은 유지합니다.
- 기존 설정·단축키·대화·메모·첨부자료를 유지합니다. 업데이트는 EXE만 교체합니다.

## 검증과 남은 확인

집중 UI/메뉴 검사 9종, 업데이트 설치·복구·자료 보존 15개 검사 및 첫째/둘째 줄 기능별 켜기·끄기 16개 합성 입력 조합을 통과했습니다. 입력 처리 중 UI 쓰기 및 기록 구간 내 앱의 텍스트·선택·글꼴 재설정은 0건입니다. 추적 기능은 테스트에서만 활성화하며 입력 내용/문자 코드는 기록하지 않습니다.

**합성 IME 알림과 확정 문자 자동 검사이며, 실제 Microsoft 한글 입력기의 16~33ms 캐럿 왕복이 해결됐다고 확정하지 않습니다.** 사용자 요청에 따라 실제 화면 조작 없이 자동 검사만 진행했습니다.

1. 메시지와 메모의 첫 줄에서 한글을 연속 입력하거나 잠시 멈췄다 이어 입력할 때 커서가 왕복하는지 확인해 주세요.
2. 둘째 줄과 비교하고, 커서만 움직이는지 글자 순서도 바뀌는지 확인해 주세요.
3. 안내 문구·검정 조합 표시 개선과 Enter/Shift+Enter, 표·이미지 붙여넣기, 메모 자동저장이 유지되는지 확인해 주세요.

## 업데이트

앱에서 **설정 / 단축키 / 테마 → 업데이트 채널 → 베타 먼저 받기(정식 포함)**를 선택한 뒤 **업데이트 확인**을 실행하세요.
