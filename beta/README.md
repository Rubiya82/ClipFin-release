# ClipFin Windows 1.0.59 Beta 2

단축키 설정 창과 한글 입력을 개선한 테스트 배포입니다. 최신 정식은 1.0.58이며 사용자 테스트와 명시적 승인 후 정식 배포합니다.

## Beta 1 이후 변경

- 단축키 설정 창: 컨트롤 초기화 중 중복 그리기를 줄이고, 모달 루프의 유휴 상태를 기다리지 않고 창 표시를 요청하도록 개선했습니다.
- 단축키 설정 창의 글씨·체크박스 주변 배경을 창 배경과 통일했습니다.
- 메시지 입력과 메모 제목/본문을 Windows의 인라인 TSF 지원 일반 텍스트 편집 컨트롤로 변경했습니다. 한글 조합 문자열과 선택 영역은 Windows 입력기가 처리합니다.
- 한글 조합 중 메모 자동저장·편집기 갱신을 미루고, 글꼴·읽기 전용 상태를 실제 변경 시에만 적용합니다. 커서·선택 영역·실행취소 기록을 유지하도록 개선했습니다.
- 메시지 입력 영역의 줄 수에 따른 크기 변경은 한글 조합이 끝난 후 적용합니다.
- 기존 Ctrl+Win+Z 새 메모 단축키와 사용자 지정 조합, 설정·대화·메모·첨부자료를 유지합니다. 업데이트는 EXE만 교체합니다.

## 받는 방법

앱의 **설정 / 단축키 / 테마 → 업데이트 채널 → 베타 먼저 받기(정식 포함)**를 선택하고 **업데이트 확인**을 실행하세요. Beta 1 사용자는 같은 채널에서 Beta 2로 업데이트할 수 있습니다. ZIP을 직접 받으면 기존 앱을 트레이에서도 종료한 뒤 실행 파일을 교체하세요. 자료 폴더를 삭제할 필요가 없습니다.

## 테스트 요청 및 검증 범위

1. 최초 및 반복해서 단축키 설정 창을 열 때의 대기 시간과 배경색을 확인해 주세요.
2. 메시지와 메모에서 한글을 빠르게 입력하고, 중간 삽입·Backspace·방향키·선택·실행취소 및 메시지 Enter/Shift+Enter를 확인해 주세요.
3. 메모 자동저장 중이나 새 메시지를 받을 때 입력 지연·커서 이동이 남는지 확인해 주세요.

격리 검사에서 단축키 창 생성·표시 요청은 31~62ms였지만 사용자 환경의 5초 이상 대기는 재현하지 못했습니다. 이 수치를 실제 사용자 데스크톱의 표시 완료 시간으로 보장하지 않습니다. 자동 검사는 조합 시작/끝 메시지와 완성형 한글·영문 입력, 선택·커서·실행취소 및 반복 갱신을 검사했으며 실제 Microsoft 한글 IME의 키 조합과 체감 지연은 사용자 환경에서 재확인이 필요합니다.

테스트 후 버전 번호와 함께 정식 배포 승인 여부를 알려주세요. 승인 전에는 정식 채널 1.0.58을 유지하며 Android는 변경하지 않습니다.
