# ClipFin Android 1.0.59 Beta 1

Windows 전용 기능을 제외하고, 구현된 공통 기능부터 반영하는 Android 테스트 배포입니다. 그룹 대화·연락처 그룹·메모 공유·표 기능은 후속 이식 대상이며 이번 버전에 포함하지 않습니다.

## 공개 Android 1.0.36 이후 변경

- 프로필 이름과 31개 사람·동물 아바타 선택 및 Windows 동기화
- 1:1 읽음 확인과 재연결 시 확인 재전송
- 새로 받은 파일·ClipFin 링크 자동 다운로드 (기본 꺼짐)
- 메시지 알림·소리·현재 대화 알림 생략 설정
- 라이트·다크·메신저 테마와 새 공유 링크의 다운로드 횟수 설정
- 베타 먼저 받기/정식만 받기 선택, 선택 보존 및 같은 버전 정식으로 업데이트
- 빠른 화면 전환 중 전경 서비스 시작 경쟁으로 앱이 종료되는 문제 수정
- 프로필·설정 대화상자의 라이트/다크 테마 대비 개선

기존 앱과 같은 패키지·서명키를 사용합니다. 앱을 삭제하지 않고 APK를 덮어 설치하면 기존 설정·대화·기기 인증서·수신 파일을 유지합니다. 최초 베타 APK 설치 시 기존에 채널을 선택한 적이 없으면 베타 수신을 선택합니다. 전체 메뉴 → 업데이트 채널에서 변경할 수 있습니다.

## 설치와 테스트

[Android Beta 1 APK 다운로드](https://github.com/Rubiya82/ClipFin-release/releases/download/android-v1.0.59-beta.1/ClipFin-1.0.59-beta.1-android.apk)

현재 공개 1.0.36에는 베타 채널 기능이 없으므로 첫 베타는 위 APK를 직접 받아 **기존 앱 위에 업데이트 설치**하세요. 앱을 삭제하거나 데이터 초기화하지 마세요. 이후에는 앱 내 베타/정식 업데이트를 사용할 수 있습니다. 이번 게시로 기존 Android 정식 업데이트 주소와 Windows 업데이트는 변경하지 않습니다.

1. 기존 대화·설정·수신 파일이 유지되는지 확인
2. Windows와 프로필·읽음 확인·파일 송수신 및 자동 다운로드 확인
3. 알림·테마·베타 채널 설정 및 앱 재실행 후 유지 확인
4. 화면을 빠르게 오가거나 홈으로 이동한 뒤 공유·전송이 정상인지 확인

전용 Android 15 에뮬레이터와 실제 Windows 실행 파일로 검증합니다. 실제 휴대폰·사내 Wi-Fi/절전 정책과 이동통신 외부망은 별도 확인이 필요합니다. 클라우드 푸시나 백그라운드 상시 메시지 수신을 추가한 버전은 아닙니다.

사용자 테스트 및 명시적 승인 후 정식 배포합니다.

검증: 실제 서명 APK의 기능 검사 15개, Windows 상호운용, 동일 서명 업데이트 자료 보존과 하향 설치 거부, JVM WireTest 통과. lintRelease 오류 0개(경고 16개). 실기기 확인은 남아 있습니다.
